## There are two different  access levels in Cisco IOS software that provides different groups of commands for a networking device:

### User Exec Mode:
This is the unprivileged mode that allows basic monitoring commands, such as checking memory resources and seeing which version of IOS is running.
The default privilege level for user EXEC mode is 1.

### Privilege Exec Mode:
This is the privilege mode that allows access to all router commands, including advanced testing commands and configuration modes. The default privilege level for privilege Exec mode is 15.

#### To Enter privilege EXEC mode, you can:
1. Enter the `enable/en` command at the IOS prompt.
2. If a password is configured, you will be prompted to enter it.
3. The IOS prompt will change from > to # to indicate you are in privilege mode.
4. To exit from Privilege Exec mode you can type exit/disable command.
